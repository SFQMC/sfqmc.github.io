autohf.solver.constructPhi0(Tlist, N, nelec, spin_symm=SlaterType.UHF, averageSpins=False)
autohf.solver.construct_random_Phi(rng, N, nelec, spin_symm=SlaterType.UHF, delta=0.01, Phi=None)

construct a random Slater determinant as

e^{-i*delta*X} Phi_{ia}

where Phi_{ia} is a Slater determinant, X is a random symmetric matrix, and delta is a real number used to control the amplitude of the random noise.

Inputs: - rng: initialized numpy random number generator - N : number of basis set functions (number of sites * number of bands) - neelc : number of electrons as an iterable of length 2 (Nup,Ndown) - spin_symm : the desired spin symmetry of the Slater determinant

map from an initial guess in the afqmctools format to the autoHF format.

Note: generates the initial Slater determint in RepOptions.SLATERDET mode

or the reference Slater determinant in RepOptions.SLATERDET_ROT mode

For Collinear Slater determinants:

afqmctools will provide Phi[nmo,Nes[0]+Nes[1]] which should be converted to jnp.stack(Phi[:,:Nes[0]], Phi[nmo][:,Nes[0]:])

For Noncollinear Slater determinants:

simply converts to a jnp array with appropriate dimensions.

hamiltonian

class autohf.hamiltonian.AutoHFHamiltonian(source=None, settings=None, **kwargs)

Bases: object

Container class to hold Hamiltonian terms for AutoHF in internal format.

Hamiltonian terms are stored as (vals, sites) pairs, where vals is a list of unique non-zero coupling values and sites is a list of the corresponding site-index arrays at which each value appears.

Parameters:

  • source (AutoHFHamiltonian or afqmctools.Hamiltonian, optional) – If source is an AutoHFHamiltonian, performs a deep-copy (copy constructor). If source is an afqmctools Hamiltonian, reads T, U, U1, U2, J, and Heisenberg terms from it. If None (default), builds from keyword arguments.

  • settings (dict, optional) – Convenience dict for lattice geometry. Expected keys: * "L" — (Nx, Ny) tuple of lattice dimensions (required). * "Nbands" — number of orbitals per site (default 1). Takes precedence over the Nx, Ny, and Nbands kwargs.

  • **kwargs – Hamiltonian terms and lattice metadata passed directly. See add_terms for the accepted term keywords. Additional keys: * N — total number of orbitals (sites × Nbands; inferred from T or settings if omitted). * Nx, Ny — lattice dimensions (used for metadata only). * Nbands — number of orbitals per site (default 1).

  • Terms (Supported Hamiltonian)

  • ---------------------------

  • argument (Supply each term as a keyword)

  • formats. (and supply input arrays in the following)

  • T (array-like, shape (nspin, N, N)) –

    One-body hopping matrix. Implements \(\\sum_{ij,\\sigma} T_{ij} c_{i\\sigma}^\\dagger c_{j\\sigma}\).

    Must be a list/tuple/ndarray with one NxN matrix per spin sector: (T_up, T_dn) for collinear (UHF) or [T_total] for non-collinear (GHF).

  • U (scalar, 1-D array of length N, or NxN matrix) –

    On-site Hubbard interaction. Implements \(\\sum_i U_i n_{i\\uparrow} n_{i\\downarrow}\).

    Accepted forms:

    • scalar — expanded to np.ones(N) * U then diagonalized.

    • 1-D array of length N — treated as diagonal of the coupling matrix.

    • NxN matrix — all non-zero entries are used as per-orbital strengths (row indices are stored; off-diagonal entries contribute their row index, which is the intended behavior for orbital-dependent U).

  • U1 (NxN array) –

    Inter-orbital mixed-spin density-density coupling. Implements \(\\sum_{i<j,\\sigma} U1_{ij}\, n_{i\\sigma} n_{j\\bar\\sigma}\).

    Stored as _terms["U1"] = (U1vals, U1Sites) where U1Sites[k] is a tuple (i_array, j_array) of pairs with i < j and coupling value U1vals[k].

    Only the upper-triangular part of the matrix is used.

  • U2 (NxN array) –

    Inter-orbital same-spin density-density coupling (Wick-contracted with the exchange correction). Implements \(\\sum_{i<j,\\sigma} U2_{ij}\, n_{i\\sigma} n_{j\\sigma}\).

    Uses same format as U1, stored under _terms["U2"].

    Only the upper-triangular part of the matrix is used.

  • J (NxN array) –

    Hund’s coupling (HK-model form). Encodes pair-hopping and spin-flip processes between orbitals i and j. Implements \(\\sum_{i<j} J_{ij} (c_{i\\uparrow}^\\dagger c_{j\\uparrow} c_{j\\downarrow}^\\dagger c_{i\\downarrow} + h.c.)\)

    Uses same format as U1, stored under _terms["J"].

    Only the upper-triangular part of the matrix is used.

  • Jheis (NxN array) –

    Heisenberg spin-spin coupling. Implements \(\\sum_{i<j} J_{ij}\, \\vec{S}_i \\cdot \\vec{S}_j\).

    Uses same format as U1, stored under _terms["J_heisenberg"].

    Jheisenberg is an alias for Jheis.

  • Jheisenberg (NxN array) –

    Heisenberg spin-spin coupling. Implements \(\\sum_{i<j} J_{ij}\, \\vec{S}_i \\cdot \\vec{S}_j\).

    Uses same format as U1, stored under _terms["J_heisenberg"].

    Jheisenberg is an alias for Jheis.

autohf.options.process_args(args_dict=None, display=True)

Processes autoHF arguments into a single namespace using default values if not specified. Accepts arguments from either a namespace args, a dictionary args_dict, or a combination. If both are provided and set the same values, the dictionary takes priority. If neither are provided, then a namespace containing default settings is returned.

Will ignore any arguments provided which do not correspond to valid keyword arguments.

Parameters:

  • args (Namespace) – a Namespace instance containing arguments (i.e. similar to the output of argparse)

  • args_dict (dict) –

    a doct contiains arguments. If both args and args_dict set the same arguement,

    the value in args_dict takes precendence.

Return type:

SimpleNamespace
