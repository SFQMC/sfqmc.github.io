Implemented Hamiltonians

Lattice Models

Consider a model with N sites

  • T

    • \(t_{ij} c^\dagger_{i\sigma}c_{j\sigma}\)

    • size: (2,N,N) for UHF, (1,2*N,2*N) for GHF

  • U

    • \(U_i n_{i\uparrow}n_{i\downarrow}\)

    • size: (N,) vector

    • A single float will automatically be used for all sites (U=1.5 \(\to\) 1.5*np.ones(N))

  • V

    • \(V_i n_{i}n_{j}\)

    • size: (N,N) matrix

    • implemented as U1+U2

  • U1

    • \(U^1_{ij}(\hat{n}_{i\uparrow} \hat{n}_{j\downarrow} + \hat{n}_{i\downarrow} \hat{n}_{j\uparrow})\)

    • size: (N,N) matrix

  • U2

    • \(U^2_{ij}(\hat{n}_{i\uparrow} \hat{n}_{j\uparrow} + \hat{n}_{i\downarrow} \hat{n}_{j\downarrow})\)

    • size: (N,N) matrix

  • J

    • \(J_{ij} (\hat{c}^\dagger_{i\uparrow}\hat{c}^\dagger_{j\downarrow}\hat{c}_{i\downarrow}\hat{c}_{j\uparrow}+\hat{c}^\dagger_{i\uparrow}\hat{c}^\dagger_{i\downarrow}\hat{c}_{j\downarrow}\hat{c}_{j\uparrow}+\hat{c}^\dagger_{j\uparrow}\hat{c}^\dagger_{i\downarrow}\hat{c}_{j\downarrow}\hat{c}_{i\uparrow} +\hat{c}^\dagger_{j\uparrow}\hat{c}^\dagger_{j\downarrow}\hat{c}_{i\downarrow}\hat{c}_{i\uparrow})\)

    • size: (N,N) matrix
